# Movie Watchlist

A movie search and watchlist web application built with HTML, CSS, and Vanilla JavaScript.

The application uses a movie API to search for movies and allows users to add movies to a personal watchlist using the browser's `localStorage`.

## Live Demo

[View Live Demo](https://movies-omdb24.netlify.app/)

## Features

- Search for movies using a movie API
- Display movie information from API results
- Add movies to a personal watchlist
- Remove movies from the watchlist
- Persist watchlist data using browser `localStorage`
- Responsive user interface

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Movie API
- Browser localStorage

## How It Works

1. Enter a movie title in the search field.
2. The application sends a request to the movie API.
3. Matching movie results are displayed.
4. Movies can be added to the watchlist.
5. Watchlist data is stored in the browser's `localStorage`.
6. Saved movies remain available when the user returns to the application.
